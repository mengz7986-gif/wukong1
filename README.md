# robot

新机器人后台与 Telegram 接单机器人的源码归档，以服务器 2026-11-01 的代码备份为准。

## 目录

- `legacy_app/`：后台、机器人、业务模块、网页及静态资产。
- `deployment/newbot/`：现有服务器部署入口、服务定义与保护脚本。
- `docs/`：备份中已有的需求、接口及验收文档；其中状态为历史记录。
- `SOURCE_IMPORT.md`：来源、校验方式、排除项和脱敏差异。

## 使用前准备

建议使用与服务器一致的 Python 3.12，并在隔离环境中按 `legacy_app/requirements.txt` 安装依赖。

真实环境变量、数据库和业务策略配置不在仓库中，须另行安全配置。部署入口含服务器专用路径；开发者应先检查启动条件与配置加载逻辑，使用独立数据库及测试机器人。不要直接执行部署脚本连接生产环境。

本次仅完成备份代码导入、哈希比对、敏感信息扫描与 Python 语法检查，未启动服务或执行生产业务测试。
