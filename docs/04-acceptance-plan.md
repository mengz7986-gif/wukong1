# 分阶段验收计划

## A：当前离线骨架

- 初始化后客户、订单、付款、余额、库存、Outbox 均为 0。
- 示例目录与 effective 示例别名可单独初始化。
- pending 别名不能参与识别；未知商品不会静默遗漏。
- 备选不计入首选数量；联系人、电话、地址必须通过最终校验。
- 相同任务幂等键重复确认只产生一个订单和一条回执事件。
- 订单/录单/付款/物流/通知状态分离。

## B：核心事务实现

覆盖价格优先级、仓库路由、FIFO 并发防超卖、报价变化、余额不足、零价/亏损确认、取消及整笔恢复、账务与库存守恒。

## C：分单、导出与通知

覆盖北京时间跨日、计划日、前序成功、同地址额度、重启并发只释放一次、三列表互斥、导出中断及对账、unknown 不自动重发。

## D：权限、学习和界面

逐端点角色矩阵和有效载荷拒绝；学习候选人工审核/版本/撤销；18:00 安全空闲复盘；390 与 1440 实际浏览器验收。

## E：外部联调及迁移（需另行授权）

使用独立测试凭证进行 Telegram/AI/地址/汇率联调；明确迁移数据范围、账务核对、未决任务、通知不重放、维护窗口、切换点与回滚点。生产部署和机器人切换不在当前授权内。
