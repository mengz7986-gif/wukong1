# 人工账款通知目标规则

收款、预存余额调整、新增待付和账单通知共用 `telegram_accounts.notification_target`。目标解析由 `notification_routing.resolve_notification_target` 实现。

1. 用户有唯一有效的接单群绑定时，优先发送到该群。
2. 没有明确绑定时，按用户确认的规则，选择最近一次下单的群；包括已取消订单。时间相同时按订单 ID 排序。
3. 已明确解绑或转绑给其他用户的群不再作为历史回退目标。
4. 该用户完全没有可用群记录时，保留原有的私聊账户通知行为。
5. 多个有效绑定或无效群 ID 会明确报错，不猜测接收群。

原问题：只查找未取消订单，导致订单全部取消后丢失来源群并退回私聊。取消订单不应改变账户通知的来源群身份。

本次只改变新通知生成时的路由。已发送通知及历史通知行不修改、不补发，也不自动新增或更换群绑定。取消订单回执继续使用原订单来源，不受此次账款路由修改影响。

验证：23 项本地测试通过，其中 13 项覆盖群路由，10 项覆盖未来通知边界、幂等认领和送达不明保护。测试使用临时 SQLite 数据库和模拟发送，不连接生产业务接口。
