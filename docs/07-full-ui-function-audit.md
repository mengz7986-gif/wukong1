# 全后台 UI 与功能迁移审计

审计日期：2026-10-21。结论：**尚未全部迁移，禁止声称完成。**

旧候选项目包含 18 个后台模板、约 641 个可交互控件标记，以及 `api.py` 中 145 个主路由装饰器；此外还有独立路由模块。新项目目前只有仪表板、商品基础、仓库基础、价格/运费/分单基础、审计、识别/接单规则和 AI 安全配置具备部分真实写入。

## 当前状态

| 分类 | 页面 | 状态 |
|---|---|---|
| 部分可用 | 仪表板、商品管理、仓库管理、价格、运费、分单、智能接单中心、操作审计 | 仅列出的操作可用，尚未与旧功能完全等价 |
| 只有入口/占位 | 订单、用户、库存、财务、统计、待处理、异常地址 | 未迁移，不计完成 |
| 尚未建立入口 | 品牌/分类独立管理、组合商品、库存图片、订单详情/打印 | 未迁移 |
| 明确不迁移 | 风火递退役推单、生产密钥、旧客户/订单/余额/库存/Outbox | 按安全边界排除 |

## 控件规则

1. 可点击控件必须有真实结果、清晰错误或确认/取消路径。
2. 未实现操作必须使用禁用态并显示原因，禁止静态按钮伪装。
3. 每个保存动作必须有认证操作者、操作 ID、前后值、结果和关联实体审计。
4. 每页必须覆盖保存刷新、空态、搜索、筛选、部分失败、权限拒绝和 390/1440 布局。
5. 旧模板控件数量只用于发现遗漏，不作为业务完成证明。

## 当前发现的商品页缺口

- “迁移现有商品”尚未实现。
- 仓库、分类、状态筛选尚未接入。
- 商品行选择、批量删除库存和批量归档尚未实现。
- 分类展开、编辑、同步价格/预警和恢复归档口味尚未实现。
- 批量添加已开始接入，但仍需浏览器端预览/二次确认等价验收。

其余页面按 `06-ui-parity-matrix.md` 逐页推进。只有矩阵全部通过 API 与真实浏览器验收后，才能声明后台迁移完成。
